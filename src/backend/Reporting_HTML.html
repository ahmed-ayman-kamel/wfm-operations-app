    How are the reports recognized?

    By their column headers, so file names, order and tab names do not matter.

    • Voyce Performance export: Interpreter Id, Interpreter Name, Transaction Id, RequestTime, AssignedToInterpreterTime, AcceptedByInterpreterTime, SecondsToAnswer.
    • Short Calls export: a Transaction Id (TransactionId) column.
    • A tab with Accepted Codes and Short Calls columns is a previous Cleaned result and is skipped.
    The Provider Online Time Detail Report is only available when you use Fetch both reports. Uploaded files give the Voyce Performance Report only.
